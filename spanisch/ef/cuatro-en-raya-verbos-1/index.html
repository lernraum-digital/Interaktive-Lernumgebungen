Reglas del juego

So funktioniert die Partie

  1. Wähle eine Spalte. Die Aufgabe entscheidet über das nächste freie Feld.
  2. Richtig ohne Hilfe: 2 Punkte. Mit Pista: 1 Punkt.
  3. Nach dem ersten Fehler bleibt das Feld als „zweite Chance“ frei. Beim nächsten Versuch erscheint eine andere Aufgabe.
  4. Erst ein zweiter Fehler auf demselben Feld blockiert es dauerhaft. Darüber kann weitergespielt werden.
  5. Jede neue Viererreihe bringt 3 Bonuspunkte. Das Spiel läuft trotzdem weiter.
  6. Nach 18 Zügen pro Person gewinnt die höchste Gesamtpunktzahl.
