# Lernstoff-Matrix – Atrapados en la disco

## Zweck

Diese Matrix begrenzt Wortschatz und Grammatik des Spiels auf den bis zur ersten Klausur behandelten Stoff. Sie basiert auf den bereitgestellten Unterrichtsfolien, Arbeitsblättern, der Klausur von 2024 und den ergänzten Buchseiten 13, 19, 20 und 164.

Neue Aufgaben müssen sich an diese Matrix halten. Wörter, die nur für Navigation oder Atmosphäre benötigt werden, sollen aus dem Bildzusammenhang verständlich sein oder eine deutsche Hilfe erhalten.

## Ausdrücklich ausgeschlossen

- spanische Zahlwörter und Zahlenübungen
- Telefonnummern
- Buchstabier- und Alphabetübungen
- Gruppenverben aus Unidad 2, insbesondere `querer` und `tener`
- nicht eingeführte Vergangenheits- oder Zukunftsformen
- reflexive Verben außer dem eingeführten Ausdruck `llamarse`
- freie Texte, die umfangreichen zusätzlichen Wortschatz erfordern

Ziffern dürfen als reine Spielmechanik vorkommen, beispielsweise bei Codefragmenten oder Fortschrittsanzeigen.

## Grammatik

### Verbindlich aktiv

| Bereich | Erwartete Anwendung |
|---|---|
| Genus | `el/la`, häufige Endungen erkennen, behandelte Ausnahmen wie `la mano`, `la radio`, `el programa` |
| Artikel | bestimmter und unbestimmter Artikel in Singular und Plural |
| Plural | Vokal + `-s`, Konsonant + `-es`, Artikel mit anpassen |
| Subjektpronomen | `yo`, `tú`, `él/ella/usted`, `nosotros/as`, `vosotros/as`, `ellos/ellas/ustedes` |
| Pronomengebrauch | Verbform meist ohne Pronomen; Pronomen zur Betonung oder Unterscheidung |
| Fragewörter | `qué`, `cómo`, `de dónde`, `dónde`, `quién/quiénes`, `por qué`, `cuándo`, `cuál` |
| Verneinung | `no + konjugiertes Verb` |
| Präsens | regelmäßige Verben auf `-ar`, `-er` und `-ir` |
| `ser` | Identität, Herkunft, Beruf, Eigenschaft |
| `estar` | Ort und Befinden |
| Kongruenz | ausgewählte Nationalitäten und Berufe in männlicher/weiblicher Form |

### Nicht als neue Grammatik prüfen

- Stammwechsel
- unregelmäßige Verben außerhalb der eingeführten Formen von `ser` und `estar`
- Objektpronomen
- Possessivbegleiter als eigener Prüfungsschwerpunkt
- komplexe Satzverknüpfungen

## Aktiver Verbwortschatz

Diese Verben dürfen in Konjugations- und Produktionsaufgaben verwendet werden:

| Verb | Kernbedeutung | Typischer Kontext |
|---|---|---|
| `ser` | sein | Herkunft, Beruf, Identität, Eigenschaft |
| `estar` | sein/sich befinden | Ort, Befinden |
| `llamarse` | heißen | Vorstellung, feste Formen `me llamo`, `se llama` |
| `hablar` | sprechen | Sprachen, Gespräche |
| `charlar` | plaudern | Treffen, Party |
| `estudiar` | lernen/studieren | Schule, Fächer, Sprachen |
| `trabajar` | arbeiten | Beruf und Arbeitsort |
| `practicar` | üben | Sprache üben |
| `quedar` | sich verabreden | feste Wendungen im Dialog |
| `vivir` | wohnen/leben | Wohnort |
| `aprender` | lernen | Sprachen lernen |
| `leer` | lesen | Texte lesen |
| `escribir` | schreiben | Texte schreiben |
| `comer` | essen | einfache Verbkonjugation |
| `beber` | trinken | Party-/Café-Dialog |
| `comprender` | verstehen | Texte und Sprachen verstehen |

### Nur rezeptiv oder in stark gestütztem Kontext

- `necesitar ayuda`
- `tomar un café / tomar algo`
- `funcionar`
- `subir`
- `escuchar`
- `presentar`
- `contestar`
- `completar`
- `ordenar`
- `unir`

Die letzten Verben können als Aufgabenoperatoren vorkommen, sollen aber nicht ohne Hilfe abgefragt werden.

- `Estoy bien / muy bien / regular / mal.`

- `Se llama ...`

## Regeln für neue Aufgaben

1. Jede neue Aufgabe nennt in den Daten ihr Lernziel.
2. Neue Inhaltswörter stammen aus dieser Matrix.
3. Atmosphärische Wörter erhalten bei Bedarf eine deutsche Hilfe.
4. Eine Aufgabe prüft möglichst nur einen neuen Schwerpunkt gleichzeitig.
5. Transferaufgaben kombinieren ausschließlich zuvor geübte Teilkompetenzen.
6. Zahlen und Unidad-2-Gruppenverben werden nicht verwendet.
7. Bei Akzentfehlern wird die richtige Schreibweise erklärt; sie führen bei rein grammatischem Fokus nicht zwingend zum vollständigen Scheitern.
8. Freie Produktion erfolgt zunächst mit Satzbausteinen, damit unbekannter Wortschatz die Lösung nicht blockiert.
